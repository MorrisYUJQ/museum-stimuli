# British Museum English Stimuli

This folder is the English replacement stimulus set for the museum dyslexia experiment.

## Files

- `index.html`: preview page showing all five exhibit items.
- `stimuli.js`: source data for the preview page, including original, Dyslexia Helper, and DFT-GEN Focus versions.
- `questions.csv`: English multiple-choice comprehension questions, five per item, ten questions in total.
- `selected_items.json`: selected exhibit list and official British Museum source URLs.

## Selected Items

1. The Parthenon
2. The Gayer-Anderson Cat

## Notes

- S1 and S2 align with the two items currently named in the manuscript's Study 3 stimulus description.
- All participant-facing question prompts and options are in English.
- The source URLs point to British Museum public pages; before final deployment, a human should do one final factual check against the live pages.
