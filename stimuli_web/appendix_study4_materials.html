Appendix D - Study 4 materials

Study 4 Materials (Chinese mainland sample and English international sample)

Full reading materials for the two Study 4 stimuli (S1, S2) across the three between-subjects conditions (Original, Dyslexia Helper, DFT-GEN), reproduced exactly as delivered on the live survey pages.

Provenance note. The Chinese-language survey pages (Credamo, mainland sample) and the English-language survey pages (international sample) were both served from the same GitHub Pages app (morrisyujq.github.io/museum-stimuli) at different points in the data collection timeline. The Chinese materials below are reproduced from the exact repository state that was live during Chinese data collection (commit 676ec1a); the site's underlying data was later replaced with the English British Museum materials for the international sample (commit 4239836 onward, currently live). Because GitHub Pages always serves the latest deployed commit, the bare Chinese survey links no longer reproduce the Chinese text if opened today - this page exists so reviewers can read the exact text each group saw. The real survey URLs (with their original labels) used for each group are listed under each language section for verification (all six Chinese and six English stimulus/condition combinations are now included). Note that these survey URLs are the live single-page app route (index.html read via ?stimulus=...&condition=... query parameters), not individual files in the repository, so they will not appear as a distinct entry when browsing the repository's file tree on GitHub or on the anonymous mirror - the app itself, and the content it currently serves, is what changed over time.
